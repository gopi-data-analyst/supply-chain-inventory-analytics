# Supply Chain and Inventory Analytics

## Project Overview

This project analyses supply chain, inventory, warehouse, supplier, and purchase-order data using MySQL.

The objective is to identify stock-out risks, evaluate supplier performance, measure warehouse efficiency, analyse product demand, and support better inventory-planning decisions.

## Business Questions

- Which products and warehouses experience stock-outs?
- Which inventory records have breached reorder thresholds?
- What is the inventory turnover ratio?
- Which suppliers deliver orders on time?
- Which suppliers have the highest delivery delays?
- Which warehouses face the greatest demand pressure?
- Which products are fast-moving or slow-moving?
- Which categories generate the highest estimated revenue?
- Which products generate the highest estimated profit?
- How stable is product demand over time?
